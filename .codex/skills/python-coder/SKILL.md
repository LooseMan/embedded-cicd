# Python coding rules

このスキルは、今回のようなPython製のファイル転送ツールを作成・改修するときに適用する。

## 設定

- コマンドライン引数は、原則としてJSON設定ファイルのパスだけにする。
- 接続情報はホスト単位のオブジェクトにまとめる。ホスト名、ポート、ユーザー名、パスワード、リモートパスを同じオブジェクトに置く。
- ファイル名の正規表現など、複数の転送先で共通する値はトップレベルで一度だけ定義する。
- 認証情報をJSONへ平文で記載する要件には対応できるが、設定ファイルをリポジトリへ登録しないことと、ファイル権限を制限することを明記する。

## 構成と重複排除

- 複数のスクリプトで使う設定読み込み、接続、レガシーSSH対応、ファイル抽出、mode処理は共通モジュールへ切り出す。
- 接続先や設定値はdataclassなどの値オブジェクトで表し、接続の開始・終了はコンテキストマネージャで管理する。
- 実行スクリプトは、設定取得・対象抽出・転送という用途固有の流れに集中させる。
- 同じ処理を少しだけ変えて複製せず、共通関数・クラスへ集約する。ただし、将来の用途が不明な過剰な抽象化は避ける。

## 制御フロー

- `try`、`with`、`if`、`for` の制御構造は、目安として3レベル以内にする。
- 深くなった場合は、ファイル抽出・1ファイルの転送・接続処理などを関数へ分割する。
- 関数内関数を増やして見かけだけ浅くせず、再利用できる処理はモジュールレベルへ置く。

## 転送仕様

- 指定ディレクトリ直下のファイルだけを対象とし、サブディレクトリは再帰走査しない。
- ファイル名の正規表現は、意図しない部分一致を避けるため完全一致を基本とする。
- 転送後は元ファイルのmodeを取得し、転送先へ`chmod`で設定する。所有者・グループ変更までは行わない。
- SFTPから別SSHサーバへ中継する場合は、ローカルを一時ステージとして使い、処理終了時に一時ファイルを削除する。
- SCP相当のSSH転送には、ParamikoのSFTP over SSHを使用してよい。接続方式は設定で切り替えられるようにする。

## レガシーSSH

- RHEL 5系などの古いサーバへ接続する場合は、転送先ホスト単位の`legacy`設定で互換モードを有効化する。
- 旧KEX、`ssh-rsa`／`ssh-dss`、CBC系暗号、旧MACなどは、通常接続へ一律に追加せず、互換モードでのみ候補に加える。
- Paramikoが提供するアルゴリズムだけを候補へ追加し、未対応方式を設定して接続自体を壊さない。

## 検証

変更後は少なくとも次を実行する。

```bash
python3 -m py_compile python/*.py
python3 -m json.tool path/to/config.json
python3 python/upload_module.py --help
python3 python/download_module.py --help
```

実サーバへ接続できない場合は、構文・設定検証済みであることと、未実施の接続テストを分けて報告する。
